Вопрос: Как настроить Git и сгенерировать SSH-ключ?
Ответ:
1. Откройте терминал.
2. Введите: ssh-keygen -t rsa -b 4096 -C "ваш_email@company.ru"
3. Нажимайте Enter (сохраняем в папке по умолчанию).
4. Скопируйте публичный ключ: cat ~/.ssh/id_rsa.pub
5. Добавьте этот ключ в свой профиль на GitLab/GitHub в разделе Settings -> SSH Keys.

Вопрос: Какие IDE (редакторы кода) рекомендованы в компании?
Ответ: Стандарт де-факто — VS Code (с плагинами для Python/JS и Prettier). Для Java-разработчиков — IntelliJ IDEA Ultimate (лицензию предоставляет компания по запросу). Для фронтенда также отлично подходит WebStorm.
