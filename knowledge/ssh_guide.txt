Как настроить SSH для Git:
1. Откройте терминал.
2. Введите команду: ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
3. Нажимайте Enter, чтобы сохранить ключ в стандартной папке (~/.ssh/id_rsa).
4. Скопируйте публичный ключ. Для macOS/Linux: cat ~/.ssh/id_rsa.pub. Для Windows: type %USERPROFILE%\.ssh\id_rsa.pub
5. Откройте ваш Git-сервер (GitHub/GitLab), зайдите в Настройки -> SSH Keys.
6. Вставьте скопированный ключ и сохраните.

Если SSH не работает, проверьте права доступа к папке .ssh (должно быть 700) и к файлу id_rsa (должно быть 600).
