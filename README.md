# AI-buddy — помощник адаптации стажёров

**Демонстрационный Web/AI MVP для хакатона Авито.** Интерфейс стажёра,
кабинет наставника, задачи с дедлайнами, вопросы наставнику и AI-помощник с
базой знаний. Используются **синтетические тестовые данные**; приложение не
подключается к настоящим корпоративным сервисам Авито.

## Быстрый запуск без AI-ключей (рекомендуемый для проверки жюри)

Нужен установленный Docker Desktop.

```bash
docker compose up --build
```

Откройте **http://localhost:5001**. База SQLite хранится в Docker volume
`ai_buddy_data` и сохраняет состояние между перезапусками.

В этом режиме `/chat` — **сценарная демонстрация**, а не вызов LLM.
Работают задачи, профиль, кабинет наставника, дедлайны и обращения.

## Единый сервер с подключаемым RAG

В файле [`docs/AI_INTEGRATION.md`](docs/AI_INTEGRATION.md) описаны режимы,
архитектура, проверки и ограничения. В отличие от старого `app.py`,
`unified_app.py` объединяет Flask API задач, кабинет наставника и чат.

```bash
# В уже подготовленном Python-окружении:
AI_MODE=demo python unified_app.py

# При установленных LangChain/Yandex-зависимостях и настроенных ключах:
AI_MODE=rag python unified_app.py
```

Настройка ключей: скопируйте `.env.example` в `.env` и укажите настоящие
`YANDEX_FOLDER_ID` и `YANDEX_API_KEY` **только локально**. `.env` не должен
попадать в Git. После запуска проверьте `GET /health`: режим `rag` означает,
что цепочка построена; `demo` + `degraded` — безопасный откат при ошибке
инициализации. Действительный ответ модели нужно проверить отдельно.

**Важно:** обычный Docker Compose по-прежнему запускает старый *demo*.
Чтобы запустить **единый Flask-сервер в Docker без AI-ключей**, используйте
неразрушающий override:

```bash
docker compose -f compose.yaml -f compose.unified.yaml up --build
```

Реальный RAG пока запускается через `unified_app.py` в настроенном окружении;
AI Docker образ не объявлен готовым без проверки зависимостей Антона.

## Основные возможности

- Стажёр: чек-лист, прогресс, сроки, фильтры, локальный демопрофиль.
- Наставник: назначение задач и дедлайнов, просмотр прогресса, ответы на вопросы.
- SQLite: задачи, статусы, сроки, история обращений (сохраняются между запусками).
- Чат: демосценарии или RAG по `.txt`-файлам `knowledge/`.
- В RAG-режиме чат получает роль, команду и этап стажёра плюс актуальные задачи.
- Подтверждение завершения задачи из чата: только по явному запросу с точным
  названием задачи и **после нажатия кнопки**. Это не LLM Tool Calling.

## Архитектура

```text
Browser (HTML/CSS/JavaScript)
        | HTTP / JSON
        v
unified_app.py (Flask)
    |-- routes/tasks.py   ----> SQLite data/ai_buddy.db
    |-- routes/mentor.py  ----> SQLite
    |-- /chat (AI_MODE=demo) --> demo_chat.py
    `-- /chat (AI_MODE=rag)  --> rag.py (YandexGPT + FAISS + knowledge/*.txt)
```

Проверяемые URL: `/health`, `/chat`, `/users/1/tasks`, `/mentor/tasks`,
`/mentor/questions`. Полное описание API в `docs/AI_INTEGRATION.md`.

## Тесты

```bash
npm ci
npm run test:coverage
python -m pytest -v
```

JavaScript-тесты используют Vitest + jsdom. Python-тесты используют pytest
и изолированную SQLite-базу. Тесты единого сервера применяют подмену RAG,
поэтому **не подтверждают доступность облачного Yandex API**.

## Короткое демо для защиты

1. Наставник создаёт задачу с датой выполнения.
2. Стажёр открывает чек-лист и видит новую задачу и прогресс.
3. Стажёр задаёт вопрос AI про свои задачи, при настроенном RAG видит ответ
   с учётом профиля и источниками.
4. Стажёр подтверждает завершение конкретной задачи.
5. Наставник видит изменение статуса.
6. Стажёр отправляет вопрос наставнику, наставник отвечает.

## Границы MVP

**Нет реальной авторизации и разграничения ролей.** Демороль наставника
доступна любому посетителю демонстрации. Не разворачивайте проект в публичном
интернете с реальными данными. Профиль хранится в localStorage, а
документы `knowledge/` — демонстрационные. Интеграция со сторонними
корпоративными API и LLM Tool Calling пока не реализована.

## Команда и стек

Хакатон Web/AI: Python 3.11+, Flask, SQLite, JavaScript, Docker Compose,
pytest, Vitest, опционально YandexGPT + FAISS/LangChain.
