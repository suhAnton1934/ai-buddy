ДЕМО-ДОКУМЕНТ. Не является внутренней инструкцией Авито.

Первая неделя в учебной Backend-команде:
1. Получить от наставника ссылку на учебный репозиторий.
2. Настроить SSH по действующей инструкции команды.
3. Клонировать учебный проект и запустить его локально.
4. Создать отдельную Git-ветку для учебного изменения.
5. Создать Pull Request и попросить наставника проверить изменения.

Если доступа нет, отправьте вопрос наставнику через AI-buddy.
