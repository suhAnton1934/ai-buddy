# SDD — AI-buddy (демонстрационная спецификация)

## Цель и границы

Помочь стажёру пройти первые задачи, сократить повторяющиеся вопросы наставнику.
Приложение — MVP без аутентификации и интеграций с реальными корпоративными API.
Пользователь `user_id=1` является единственным демонстрационным стажёром.

## Компоненты и поток данных

```text
Браузер (JS/CSS/HTML)
  -> Flask: unified_app.py
    -> routes/tasks.py, routes/mentor.py, tickets.py -> SQLite (data/ai_buddy.db)
    -> mentor_intelligence.py -> ChatYandexGPT (в RAG-режиме), SQLite
    -> team_memory.py -> одобренные ответы наставника в SQLite
    -> knowledge_sync.py -> mock_corporate_docs/*.txt -> knowledge/synced/*.txt
    -> /chat -> demo_chat.py ИЛИ rag.py (YandexGPT + FAISS)
```

## Функциональные сценарии / ожидаемые результаты

1. **Назначение задачи:** наставник вводит название, описание, дедлайн;
   после подтверждения запись появляется у стажёра и в кабинете наставника.
2. **Диалог:** стажёр отправляет вопрос; наставник отвечает; переписка и статус
   сохраняются в SQLite. Отвеченное обращение можно закрыть и найти в архиве.
3. **AI-разбор:** только при `AI_MODE_ACTUAL=rag` и наличии ответа наставника.
   `POST /mentor-ai/analyze` получает ID обращения и необязательный followup;
   модель возвращает объяснение, извлечённые шаги и вопросы на уточнение.
   При невозможности получить ответ модель не создаёт задачи.
4. **AI-план:** после разбора стажёр предлагает шаги; наставник отдельно
   утверждает/отклоняет их; только утверждённые шаги становятся задачами в SQLite.
5. **Team Memory:** наставник явно публикует свой ответ; поиск проверяет
   текстовое сходство с запросом, а изменение ответа отзывает старую публикацию.
   Это **не** обучение модели и не гарантия семантического поиска.
6. **Синхронизация:** документ загружается из разрешённого источника,
   валидируется, сохраняется как `.txt`; при работающем RAG выполняется попытка
   пересоздания индекса. Используются синтетические документы.
7. **Имитация заявки:** команда пользователя создаёт запись обращения в SQLite;
   никаких реальных корпоративных прав не изменяет.

## Примеры API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/health` | `mode`, `requested_mode`, `rag_ready`, `status` |
| GET | `/users/1/tasks` | Список задач |
| PATCH | `/tasks/<id>` | Обновление статуса по явному запросу |
| POST | `/chat` | Чат demo или RAG / проверенные ответы Team Memory |
| GET/POST | `/mentor/questions` | Вопросы стажёра / отправка обращения |
| POST | `/mentor/questions/<id>/reply` | Ответ наставника |
| POST | `/mentor-ai/analyze` | AI-разбор ответа |
| POST | `/mentor-ai/proposals` | Предложить план |
| GET | `/mentor-ai/proposals?user_id=1` | Планы на рассмотрении |
| POST | `/team-memory/publish` | Опубликовать подтверждённое знание |
| GET | `/team-memory/entries` | Проверенные знания |
| GET | `/knowledge-sync/status` | Статус синхронизации |
| POST | `/knowledge-sync/run` | Синхронизировать синтетическую документацию |

Точные поля запросов, условия кодов ошибок и ограничения находятся в коде и `docs/`.

## Доступы и безопасность

- Настоящих ролей/аутентификации нет; приложение предназначено только для локальной демонстрации.
- Ключи Yandex Cloud — только через локальный `.env`, игнорируемый Git.
- Нет автоматического применения рекомендованных AI-шагов, нужен наставник.
- Не хранить настоящие пароли, токены, персональные данные стажёров.
- FAISS-кеш/локальная индексация должны использовать только доверенные файлы.

## Отказоустойчивость и границы подтверждения

- Неуспех RAG при старте: `/health` показывает `status: degraded`, чат переходит в demo.
- AI-разбор при недоступном RAG: `503`, исходный ответ наставника сохраняется.
- Ошибка внешнего вызова модели: `503`; прежний ответ наставника не перезаписывается.
- Отказ синхронизации не должен подменять рабочую цепочку новой ошибочной.
- Неправильные данные: сервер возвращает 400/403/404/409 в зависимости от операции.

## Критерии приёмки и проверки

- Демозапуск без ключей доступен на порту 5001, есть UI и `/health`.
- RAG-запуск с ключами: `mode=rag`, `rag_ready=true` и успешный реальный запрос к модели.
- Ответ наставника создаёт видимую кнопку AI-разбора, которую можно нажать.
- Предложенные AI-шаги не появляются в задачах до утверждения наставником.
- Проверенный ответ Team Memory повторно доступен с указанием источника.
- Корпоративная имитация создаёт запись в SQLite, без внешних операций.
- Прогон pytest и Vitest проходит; покрытие измеряется отдельно для Python и JS.
