# Контроль перед отправкой хакатона

- [ ] Скопировать `.env.example` в `.env`, добавить действительные секреты **локально**, проверить что `git ls-files .env` пуст.
- [ ] `docker compose -p ai-buddy up -d --build` работает в demo без ключей.
- [ ] `docker compose -p ai-buddy -f compose.yaml -f compose.rag.yaml up -d --build` собирается и запускает RAG при настоящих ключах.
- [ ] `/health`: `mode=rag`, `rag_ready=true`; получить **живой ответ** YandexGPT в чате.
- [ ] Ответ наставника → кнопка «Разобрать ответ с AI» → результат AI-разбора.
- [ ] AI-план создаёт задачи **только после утверждения** наставником.
- [ ] Team Memory публикуется наставником, ответ извлекается в чате.
- [ ] Имитация корпоративной заявки создаёт запись обращения в SQLite.
- [ ] После обновлений запущены pytest и Vitest; сохранены полные проценты покрытия без пропущенных модулей.
- [ ] README и SDD соответствуют финальному коду, без заявлений о недоступных интеграциях.
- [ ] Добавить ссылку на фактически снятое видео в README или на первый слайд PDF, либо приложить видео в комплекте сдачи.
- [ ] Приложить презентацию в PDF и убедиться, что ссылки открываются.
- [ ] `git status` чист, нет `.env`, БД, `.venv`, архивов с секретами в `git add`.
